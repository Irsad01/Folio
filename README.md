# ATS Resume Builder

A modern, responsive, and feature-rich **ATS (Applicant Tracking System) Resume Builder** built using **HTML, CSS, and JavaScript**. Create professional resumes with live preview, customizable sections, multiple templates, and export your resume as a PDF.

---

# 📖 Overview

ATS Resume Builder helps job seekers create resumes that are optimized for Applicant Tracking Systems while maintaining a clean and professional design.

The application provides a real-time editing experience where every change is instantly reflected in the resume preview.
